item_master.xlsx — it's a reference/lookup table: item name, shelf life, base item name, combo flag, breakdown. It doesn't change month to month 
the way sales reports do. It's closer to a dimension table in data warehouse terms, while the other 4 are fact tables (transactions over time).

Fact tables (changes every month):
  daily-sales/, menu-mix/, item-wise/, online-orders/
  → one file per month, append-only over time

Dimension table (relatively static):
  item_master.xlsx
  → describes the menu itself, updated only when 
    menu items are added/removed/renamed
